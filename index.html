03 / operating principles

Menos ruído.
Mais máquina.

A tecnologia fica melhor quando você entende o que ela faz, consegue mudar seu comportamento e não paga por abstrações que não precisa.

Performance é uma funcionalidade.

Inicialização rápida, baixo uso de memória e trabalho feito perto do sistema — não como detalhe, mas como parte do produto.

Local primeiro.

Ferramentas standalone, fluxos offline e dados sob controle do usuário sempre que o problema permite.

Interface sem mistério.

Terminal, logs e configurações legíveis. O usuário deve enxergar decisões e consequências antes de apertar Enter.

Open source de verdade.

Código disponível para estudar, auditar, adaptar e manter vivo — inclusive quando o projeto original perde ritmo.
