🌸 SILICONFLOWER

Agente CLI/TUI de Inteligência Artificial para Windows com suporte nativo a Model Context Protocol (MCP), Raciocínio Controlável, Contador de Tokens em Tempo Real e 3 Modos de Operação.

⚡ Ultra Rápido & Leve

Desenvolvido em TypeScript com runtime Bun / Node.js. Sem necessidade de Nerd Fonts ou configurações complexas.

🧠 Modos & Raciocínio

Alternância dinâmica entre Programação, Sistema e Plano, combinados com níveis de Reasoning (`none` a `high`).

📦 Standalone .exe

Compilado em executável único para Windows, rodando diretamente no seu terminal do PowerShell sem dependências.

Visão Geral dos Recursos

Recursos do SiliconFlower

Área Descrição
Provedores LLM Compatível com APIs OpenAI (`/v1/chat/completions`) e Anthropic (`/v1/messages`). Suporta SiliconFlow, OpenRouter, etc.
Contador de Tokens Contagem em tempo real na TUI com estimativa local instantânea + metadados exatos da API.
Raciocínio Controlável Níveis `none`, `low`, `medium` e `high`. Envia `reasoning_effort` ou `thinking` com `budget_tokens`. Alternável com `Ctrl+E`.
Modos de Operação `programação` (código), `sistema` (administração Windows) e `plano` (apenas leitura/planejamento). Alternável com `Ctrl+O`.
Ferramentas Nativas Leitura/escrita de arquivos, busca recursiva (`grep_content`), edição atômica (`apply_patch`), execução no PowerShell, subagentes (`run_task`).
Protocolo MCP Suporte completo a servidores MCP via `stdio` (ex: Git, Filesystem, Brave Search) mesclando ferramentas dinamicamente.
Habilidades (.md) Carregamento dinâmico de guias personalizadas na pasta `~/.siliconflower/skills/*.md`.
Recursos Principais:
Ponto chave: SiliconFlower une ferramentas locais seguras, MCP extensível e raciocínio profundo em uma só ferramenta para Windows.

Controle Total de Execução

Modos de Operação & Raciocínio

🎭 Modos de Operação (Ctrl+O)

programaçãoCódigo & Refatoração

Focado em leitura, escrita, revisão de código e automação de desenvolvimento seguindo o padrão do projeto.

sistemaAdministração Windows

Permite execução de scripts PowerShell, backups, gerenciamento de serviços e tarefas do sistema.

planoSegurança & Apenas Leitura

Bloqueia edições e comandos modificadores. O agente apenas analisa e propõe o plano para sua aprovação.

🧠 Níveis de Raciocínio (Ctrl+E)

nonelowmediumhigh

Ajusta o nível de pensamento lógico conforme a complexidade do desafio:

  • DeepSeek / OpenAI: Envia parâmetro `reasoning_effort`.
  • Anthropic: Ativa modelo `thinking` com orçamento dinâmico de `budget_tokens`.
  • Permite economia de custos em tarefas simples e máximo poder analítico em refatorações complexas.
Modos e Raciocínio:
Explique a importância do modo 'plano' para segurança quando o usuário quer apenas auditoria ou planejamento.
O atalho Ctrl+E permite alternar o raciocínio sem reiniciar a sessão.

Arquitetura Extensível

Ferramentas Nativas & Protocolo MCP

🛠️ Ferramentas Nativas Incorporadas

read_file - Leitura com offset/limit

write_file - Criação de arquivos

edit_file - Substituição precisa

apply_patch - Edição atômica multi-bloco

grep_content - Busca por regex

search_files - Filtro com padrões Glob

execute_command - PowerShell silencioso

run_task - Subagente isolado

todowrite - Painel de tarefas da sessão

ask_question - Perguntas interativas

read_logs - Filtro de logs da sessão

delete_path - Exclusão protegida

🛡️ Proteção ativa: timeout de 60s, janelas ocultas e bloqueio de pastas sensíveis (System32, .ssh, .aws).

🧩 Protocolo MCP (Model Context Protocol)

Conecte qualquer servidor MCP diretamente na sua configuração (`config.json`):

"mcpServers": { "git": { "command": "uvx", "args": ["mcp-server-git", "--repository", "C:/meu-repo"] }, "filesystem": { "command": "npx", "args": ["-y", "@modelcontextprotocol/server-filesystem", "C:/Users"] } }

As ferramentas do MCP são descobertas e mescladas automaticamente com as nativas.

Ferramentas & MCP:
Ressalte que o SiliconFlower já vem com tudo pronto para manipular arquivos e executar PowerShell com segurança.
A integração MCP abre um ecossistema gigante de ferramentas comunitárias (Git, Postgres, Brave Search, etc).

Início Rápido

Instalação & Standalone .exe

1. Requisitos

• Bun >= 1.1 (Recomendado)
• ou Node.js >= 20 + `tsx`
• Windows Terminal / PowerShell

2. Execução Direta

git clone https://github.com/siliconflower/siliconflower.git cd siliconflower bun install bun run start

Na primeira vez, abre o assistente interativo (*wizard*).

3. Compilar Executável .exe

bun run build npm run install:bin

Gera `dist/siliconflower.exe` e adiciona ao seu PATH no Windows sem precisar de Admin.

⚡ Comandos CLI Úteis

bun run start -- config bun run start -- show bun run start -- -m deepseek-ai/DeepSeek-V4-Pro -r high
Instalação e Deploy:
Mostre como é simples começar. O comando `bun run build` transforma todo o agente TypeScript em um único `.exe` independente que roda direto no Windows.
