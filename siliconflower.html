🌸 Funcionalidades

O que o siliconflower faz

Um agente completo que entende seu código, gerencia seu sistema e executa tarefas complexas com inteligência.

📂

Sistema de Arquivos

Lê, cria, edita e gerencia arquivos e diretórios com precisão cirúrgica. Suporta patches atômicos e operações em lote.

read_file write_file edit_file apply_patch
💻

Execução de Comandos

Executa comandos no terminal (PowerShell/Bash) com suporte a processos em background, timeouts e captura de output.

execute_command background timeout
🔍

Navegação de Código

Mapeia repositórios, busca símbolos (funções, classes, tipos) e pesquisa conteúdo com regex em todo o projeto.

repo_map find_symbol grep_content
🌐

Acesso à Web

Pesquisa na web e busca conteúdo de páginas automaticamente, convertendo HTML em Markdown limpo para análise.

web_search web_fetch
🤖

Subagentes Autônomos

Lança subagentes para executar tarefas em paralelo ou background — pesquisas complexas, refatorações e verificações.

run_task background parallel
🧠

Memória Persistente

Salva regras de projeto, preferências do usuário e aprendizados que persistem entre sessões. Nunca perca contexto.

save_memory recall_memory scope
🔀

Git Worktrees

Cria branches de trabalho isoladas para testar mudanças com segurança, sem afetar o branch principal.

enter_worktree exit_worktree isolamento
📊

Artefatos Estruturados

Gera relatórios, diagramas Mermaid, documentos HTML, JSON e código. Tudo salvo e recuperável por ID.

create_artifact mermaid html

🌷 Como Funciona

Simples como plantar uma flor

Três passos para ter um agente de IA poderoso no seu terminal.

1

Instale

Configure o Siliconflower no seu ambiente Windows com Node.js ou Bun. Uma vez instalado, ele está pronto.

2

Converse

Diga o que precisa em português. Ele entende contexto, lê seu projeto e planeja antes de agir.

3

Construa

Ele executa: cria arquivos, edita código, roda comandos, faz commits e muito mais — tudo pelo terminal.

terminal exemplo de uso

$ siliconflower
